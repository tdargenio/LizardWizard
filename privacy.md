# Privacy Policy for Ask the Gecko

**Last updated: September 24, 2026**

Ask the Gecko is a Chrome extension that provides occupation matching, comparison results, Knowledge Hive search and article previews, NY POR tools, and related workplace utilities.

This Privacy Policy explains what information Ask the Gecko accesses, how that information is used, and what choices users have.

## Information the Extension Accesses

Ask the Gecko may access the following information when a user actively uses an extension feature:

- Job titles, occupation descriptions, and other text entered by the user
- User selections, extension settings, theme preferences, recent searches, and saved workflow state
- Occupation-matching feedback supplied by the user
- Knowledge Hive search terms and selected search results
- Content from a Knowledge Hive article selected by the user for preview
- The URL, title, loading status, and window information for tabs used by an extension feature
- Information needed to complete a user-requested NY POR lookup or calculation
- Calculator inputs entered by the user

Ask the Gecko does not continuously monitor general browsing activity.

## How Information Is Used

Information is used only to provide the extension’s user-requested features, including:

- Matching user-entered job titles with occupation options
- Displaying occupation comparison results
- Maintaining the extension’s two-step review workflow
- Remembering extension settings and recent workflow activity
- Searching Knowledge Hive
- Opening a selected Knowledge Hive result
- Displaying a readable preview of a selected Knowledge Hive article
- Performing NY POR lookups and related calculations
- Restoring extension state when the popup or side panel is reopened
- Improving future occupation matches using feedback intentionally provided by the user

The extension does not use information for advertising or unrelated profiling.

## Local Storage

Ask the Gecko uses Chrome extension storage to save information such as:

- Extension preferences
- Theme settings
- Recent searches
- Current workflow state
- Occupation-matching feedback
- Cached Knowledge Hive article links
- Calculator inputs

This information is stored through the browser’s extension storage system so that extension features and preferences can be restored.

Users can remove locally stored extension information by uninstalling the extension or clearing the extension’s stored data through Chrome.

## Active Tab and Scripting Access

Ask the Gecko may temporarily access the active tab after the user invokes the extension or selects a feature.

The extension uses scripting access for user-requested Knowledge Hive functionality, including:

- Entering a search request
- Applying search controls
- Reading the displayed search-result table
- Activating a result selected by the user
- Extracting readable content from the selected article for an in-extension preview

Ask the Gecko does not inject scripts into unrelated websites for advertising, tracking, or browsing surveillance.

## Tab and Window Access

Ask the Gecko uses Chrome’s tab and window functions to:

- Find an existing Knowledge Hive tab
- Open a user-requested Knowledge Hive search or article
- Determine when a requested page has finished loading
- Create a temporary background tab when needed to generate an article preview
- Close a temporary tab after the requested preview is generated
- Return focus to the user’s original tab and window
- Open or close the Ask the Gecko side panel

Tab and window access is used only to support features initiated by the user.

## Website Access

Ask the Gecko requests access only to the following services:

- The company Knowledge Hive domain
- Microsoft’s sign-in domain

Knowledge Hive access is used to perform searches, read displayed search results, open selected articles, and produce user-requested article previews.

Microsoft sign-in access supports the authentication process required to reach protected company resources.

Ask the Gecko does not request access to all websites.

## Authentication Information

Ask the Gecko may interact with Microsoft’s sign-in pages as part of the authentication flow for protected company resources.

The extension does not intentionally collect, store, or transmit user passwords.

Authentication is handled through the relevant Microsoft and company services.

## Data Sharing

Ask the Gecko does not sell user data.

Ask the Gecko does not share user data with advertisers or data brokers.

Information may be processed by the company systems and Microsoft authentication services that the user intentionally accesses through the extension. Use of those services may also be governed by their respective privacy and security policies.

## Remote Servers

Ask the Gecko does not operate an independent analytics, advertising, or user-tracking server.

The extension communicates only with the services required for its disclosed functionality, including Knowledge Hive and Microsoft authentication.

## Analytics and Advertising

Ask the Gecko does not include third-party advertising.

Ask the Gecko does not use information collected through the extension for targeted advertising.

Ask the Gecko does not intentionally use third-party analytics to track users across websites.

## Data Retention

Locally stored extension information remains in Chrome extension storage until one of the following occurs:

- The user clears the extension’s stored information
- The extension overwrites an older saved value
- The user uninstalls the extension
- Chrome removes the extension’s stored data

Temporary tabs created to support article previews are closed after the requested operation when the extension can complete that action.

## User Controls

Users can control their information by:

- Clearing saved information through available extension controls
- Clearing the extension’s data through Chrome
- Removing the extension
- Choosing not to use Knowledge Hive or other optional workflow features
- Closing temporary tabs or the extension side panel

## Data Security

Ask the Gecko limits requested permissions and website access to the functionality described in this policy.

No method of electronic storage or transmission can be guaranteed to be completely secure. Users should avoid entering unnecessary personal, confidential, or sensitive information into free-text fields.

## Children’s Privacy

Ask the Gecko is intended as a workplace productivity tool and is not directed toward children.

The extension does not knowingly collect personal information from children.

## Changes to This Privacy Policy

This Privacy Policy may be updated when Ask the Gecko’s features, permissions, or data practices change.

The updated policy will be posted at this same public location with a revised “Last updated” date.
